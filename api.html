How FM Continuum Works

FM Continuum is a client-side web app built around the HTML audio element and Web Audio APIs. Playback logic, persistence, diagnostics, and UI are all managed in-browser.

Audio stream object

{ "id":"k95", "name":"K95 95.3 FM", "src":"https://...", "mime":"audio/mpeg", "fallbacks":["https://..."] }

Reliability model

  • Watchdog checks progress and stall conditions.
  • Reconnect uses exponential backoff with jitter.
  • Fallback stream URLs are attempted when available.

Local storage keys

  • fm.stations custom stations
  • fm.favorites favorites
  • fm.volume volume
  • fm.theme theme
  • fm.last last station

External integrations

Optional integrations include ipify, streaming providers, and policy embeds.
