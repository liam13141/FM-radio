Quick start

  • Search stations and press play.
  • Use favorites to save stations.
  • Theme preference is stored locally.

Troubleshooting

  • No sound: interact once to unlock autoplay.
  • Stream stalls: watchdog reconnects automatically.
  • Still failing: run diagnostics.

Shortcuts

Space play/pause, S stop all, M mute, / focus search.
